# Industry Atlas

A Markdown-first industry knowledge graph and visual research interface.

Industry Atlas treats industries as **views over shared entities**, not isolated folders. Companies, technologies, products, applications, regulations, events, evidence, and theses live as reusable knowledge nodes.

The first vertical is **Memory**, starting with **DDR3 / Specialty DRAM**.

> Status: project bootstrap. The first functional scaffold is developed on the `develop` branch.
